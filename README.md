# Hédy Casablanca

A concept website for Hédy, a French restaurant on the 8th floor of an Art Deco landmark at 31 Rue Jean Jaurès, Casablanca.

Static HTML, CSS and JS. No build step. Open `index.html` or serve the folder.

Reservations: https://www.sevenrooms.com/explore/hedy/reservations/create/search/
